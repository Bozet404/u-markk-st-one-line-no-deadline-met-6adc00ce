Entry for the [make.fun](https://make.fun) bounty
**"One Line, No Deadline Met"** ($2, deadline 27 Nov 2026 12:35 WIB).

## The entry

`main.py` writes exactly one single-line joke giving an excuse for a
missed deadline to `$OUTPUT_DIR/entry.txt` — that line and nothing else:
no picture, no link, no second line. The line is capped at 200 characters.

## Run it

```sh
OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
